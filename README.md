# AI Study Planner

## Abstract

AI Study Planner is a simple web-based application that helps students create a daily study plan based on their subjects and available study hours.

## Introduction

Students often find it difficult to organize their study time effectively. This project provides a simple way to enter subjects and study hours and generate a structured study plan.

## Problem Statement

Students need an easy system to manage multiple subjects and available study time efficiently.

## Proposed Solution

The AI Study Planner accepts the student's subjects and available study hours and generates a simple daily study plan.

## Features

- Enter subjects
- Enter study hours per day
- Generate a study plan
- Simple and user-friendly interface
- Daily study schedule

## Technologies Used

- Python
- Flask
- HTML
- CSS

## Users

- Students
- School students
- College students
- Competitive exam learners
